# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within EmailStudio, please report it privately via GitHub Advisory or email security@emailstudio.dev.

Please include:
- A description of the issue.
- Steps or a minimal reproduction.
- Impact assessment.

We strive to acknowledge receipt within 48 hours and coordinate a timely fix and advisory.
